# My Portfolio Website

Welcome to my portfolio website! This site showcases my projects, experience, skills, and personal growth journey.

## 📄 Pages

### 1. **Home Page** (`index.html`)
- Welcome introduction
- Quick navigation to all sections
- Call-to-action buttons

### 2. **About Me** (`about.html`)
- Personal interests and hobbies
- Activities and involvement
- Technology interests and passions

### 3. **Projects** (`projects.html`)
- 4+ programming projects
- Descriptions, screenshots/videos, and links
- Challenges faced and lessons learned for each project
- Technologies used

### 4. **Resume** (`resume.html`)
- Education background
- Technical skills
- Professional experience
- Leadership positions and activities
- Volunteer work
- Certifications and awards

### 5. **Reflection** (`reflection.html`)
- 300+ word personal and professional growth reflection
- Thoughts on challenges and learning experiences
- Future vision and goals

## 🎨 Design Features

- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Modern UI**: Clean, professional design with gradient accents
- **Navigation**: Sticky header with easy navigation between pages
- **Accessibility**: Semantic HTML and readable color schemes

## 🚀 Getting Started

1. Replace placeholder content in each HTML file with your actual information:
   - Update personal details, skills, and experience
   - Add your project information and screenshots
   - Write your reflection essay (minimum 300 words)

2. Update placeholder images:
   - Replace `placeholder-project-[n].jpg` with actual project screenshots
   - Add project links and GitHub repository links

3. Customize colors and styling:
   - Edit `styles.css` to match your personal brand
   - Change gradient colors from the purple/blue theme to your preference
