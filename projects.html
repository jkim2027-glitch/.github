Project 1: Interactive Art Studio

An interactive graphics application where users can create digital art by clicking on different colored areas of a canvas. The application features dynamic animations and real-time user input handling.

Technologies

Python CMU Graphics Graphics Programming

Key Features

  • Color-based interactive regions with visual feedback
  • Animated star burst effects and twinkling animation system
  • Real-time message input and fade-out animation
  • Complex shape composition using circles, polygons, and lines
  • Mouse event handling with collision detection
  • Dynamic property management for object visibility and state

Challenges & Lessons

The main challenge was managing multiple interactive elements and their states efficiently. I learned the importance of organizing complex graphics code with proper object management and event handling systems.
