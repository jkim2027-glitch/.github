My Projects

Programming projects showcasing my skills and learning

Project 1: Interactive Art Studio

An interactive graphics application where users can create digital art by clicking on different colored areas of a canvas. The application features an animated night sky with twinkling stars, an interactive house structure, and multiple human figures. Users can input custom messages that appear and fade away, creating a dynamic and engaging artistic experience that combines visual effects with user interaction.

Technologies

Python CMU Graphics Graphics Programming

Key Features

  • Color-based interactive regions with visual feedback
  • Animated star burst effects and twinkling animation system
  • Real-time message input and fade-out animation
  • Complex shape composition using circles, polygons, and lines
  • Mouse event handling with collision detection
  • Dynamic property management for object visibility and state

Challenges & Lessons

The main challenge was managing multiple interactive elements and their states efficiently. I learned the importance of organizing complex graphics into logical groups and handling mouse events with precise collision detection. This project taught me how to create smooth animations by manipulating object properties over time and how to build intuitive user interfaces through visual feedback.
